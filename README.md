# LeetCode Revision Tracker

A web-based LeetCode question tracking and revision management tool built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add coding questions
- Edit and delete questions
- Mark questions as Solved / Pending
- Search questions
- Filter by Topic, Difficulty, and Status
- Track total, solved, and pending questions
- Progress bar
- Daily solving streak
- Next revision date
- Revision status: Today, Overdue, and Upcoming
- Mark as Revised with automatic next revision date
- Topic-wise progress
- Difficulty-wise progress
- Achievement milestones
- LocalStorage for saving data
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📌 Project Purpose

This project helps users organize their LeetCode practice, track solved questions, and manage revision schedules in one place.
